สถานะ ดูแล้ว / สนใจ / ไม่สนใจ ตามไปทุกเครื่องที่เปิดซิงก์

ตั้งรหัสซิงก์ครั้งเดียวต่อเครื่อง หรือเปิดลิงก์ส่วนตัวจากเครื่องที่ตั้งไว้แล้ว
ลิงก์ส่วนตัวสำหรับเครื่องอื่นเปิดลิงก์นี้บนเครื่องอื่นครั้งเดียว สถานะจะตามไปเอง (อย่าแชร์ให้คนอื่น)
